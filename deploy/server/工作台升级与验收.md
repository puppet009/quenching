# 工作台升级与验收（2026-10-19）

本次修改属于用户端 web，不含数据库迁移或后端协议变更。若服务器还没完成此前日志、业务域迁移等升级，先按相应升级说明处理。

## 本次变化

- 工作台采用清晰的顶栏、桌面、侧栏、底部工具栏；沿用淬火橙色品牌和深色终端。小字号提高至可读范围，工具图标改为统一线性图标。
- 监控、告警及大脑状态放入环境侧栏；助手展开时占用侧栏空间，窗口适配剩余桌面。收起助手保留会话、流和未发送草稿。
- 窗口在实际桌面范围内移动、八向缩放、最大化与左右贴靠；聚焦不会重置坐标。桌面不足以容纳两个最小窗口时禁止新贴靠，已贴靠窗口自动最大化。
- 最小化保持窗口内容挂载，可通过底部工具栏或终端任务按钮恢复，不会因最小化断开终端或清空命令、文件编辑状态。主动关闭窗口仍会关闭对应终端连接。
- 补上原先缺失的 xterm 必要样式，隐藏内部字体测量元素；使用清晰等宽字体，支持 12–22px 调整。容器 ResizeObserver 同步终端尺寸，覆盖窗口缩放、助手和文件侧栏开合。终端保持浏览器原生 DOM 文字渲染，没有固定分辨率截图拉伸。
- 原“提交修复”入口明确为“结束实训”，确认后按原流程结束整个班次并生成复盘。退出确认说明结束班次并回收环境，取消确认不会调用结束接口。

## 已完成前序升级的服务器

默认部署镜像 tag 为 `0.1.0`。自定义 tag 需在构建时设置与现有 deployment 一致的 `IMAGE_TAG`；多节点仍需按现有流程分发镜像。本次只重建 web。

```bash
(
  set -euo pipefail
  export KUBECONFIG=/etc/rancher/k3s/k3s.yaml
  cd /data/src/quenching
  git pull --ff-only
  bash deploy/server/images.sh web
  kubectl -n platform rollout restart deployment/web
  kubectl -n platform rollout status deployment/web --timeout=5m
)
```

刷新浏览器后进入训练。建议在没有进行中实训时更新前端，避免页面刷新中断当前操作。

## 服务器验收

1. 检查标题、底部工具文字及终端可读，没有内部测量文字或图标重叠。
2. 打开真实终端，输入未提交命令；最小化并恢复后连接与文字仍在。
3. 打开助手输入草稿，收起再展开，确认草稿、历史对话保留，终端未被遮挡。
4. 拖动、缩放、最大化窗口，打开文件面板并切换浏览器尺寸；终端行列及时更新，所有标题栏可操作。
5. 多容器窗口左右贴靠后打开文件面板，再缩小浏览器，确认工具栏和文件关闭按钮可见。
6. 打开日志、监控和命令执行工具，确认原接口、操作记录、当地时区显示正常；仅在准备结束真实测试班次时确认“结束实训”。
