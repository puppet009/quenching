# 项目大厅布局升级（2026-10-31）

## 调整

- 页面标题与“我的训练”入口放在同一行，原推荐横幅不再占用独立区域。
- 搜索框缩为桌面端约 280px 宽的小输入框，与领域选择、排序、项目数量合并成紧凑工具栏。
- 保留预先定义的五大业务领域，恢复可见的紧凑分类导航；点击大类后展示其全部细分类型，无项目的类型标为“敬请期待”。固定领域来自共享 `DOMAIN_TREE`，不随项目数量隐藏。
- 分类导航与领域下拉保持同步：选择大类筛选其全部项目，选择细分类型筛选该类型，选择“全部领域”解除领域限制。切换大类会清除旧细分选择，搜索词保持不变。
- 减少顶部和区块间距，让普通笔记本首屏完整展示第一张项目卡片及进入入口。
- 保留项目名、描述、模板标识、技术栈实时搜索，以及清空搜索、领域切换、排序、加载失败重试和空结果状态。

## 部署

仅更新用户端 `web` 镜像，无数据库迁移或 Helm 配置变更。以下沿用服务器现有 `0.1.0` 镜像标签：

```bash
(
  set -euo pipefail
  export KUBECONFIG=/etc/rancher/k3s/k3s.yaml
  cd /data/src/quenching
  git pull --ff-only

  IMAGE_TAG=0.1.0 bash deploy/server/images.sh web
  kubectl -n platform rollout restart deployment/web
  kubectl -n platform rollout status deployment/web --timeout=10m
)
```

## 验收

1. 在 1366×768、1440×900 等桌面窗口进入项目大厅，无需滚动即可看到第一张项目卡片的完整内容和进入入口。
2. 搜索框不再横跨整页；搜索、领域、排序和数量处于同一紧凑工具栏。
3. 五大类始终可见；逐个切换后能浏览全部预定义细分类型，未上线类型仍可见。项目数由完整模板列表统计，不随搜索词减少。
4. 分类导航、领域下拉及结果同步；选择无项目的大类显示该领域待上线提示，不能继续展示上一类的项目。选择“全部领域”解除领域限制；有匹配项目时能正常恢复。
5. 按项目名、描述、模板标识、技术栈搜索，清空后恢复列表；无匹配结果时正常提示。
6. 项目仍可进入详情；加载失败可以重试，“我的训练”仍进入训练历史。

本地浏览器以模拟模板接口验证布局和交互；服务器真实模板列表及图片加载需部署后验收。
